# ScentCap — screenshot shot list

Capture from `npm run gallery` / device at current App Store Connect required sizes (verify 6.7" / 6.5" / iPad at upload time).

## Primary scenes

1. **Today** — hero pick / what to wear
2. **Collection** — wardrobe grid with bottle photos or monograms
3. **Advisor** — recommendation flow
4. **Settings → About** — disclaimer visible (“Brand names belong to their owners…”)

## Rules

- Sample / demo wardrobe only (no personal photos in marketing shots).
- Light appearance; one dark set optional.
- No splash, debug banners, or Pro / paywall UI (G-2).
