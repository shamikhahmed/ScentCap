# ScentCap — Monetization

## Model: Completely free

ScentCap is a free PWA. No Stripe, no IAP, no Pro tier, no bottle limits, no paywalls.

All features (Collection, Advisor, Analytics, Layering Lab, Travel Kit, export) ship unlocked for everyone.

## Why free

- Local-first fragrance wardrobe OS — no accounts, no cloud lock-in
- Hobby tool, not SaaS billing surface
- Payment theater (stubs, launch-preview flags, Pro gates) removed from codebase

## Not planned

- Stripe / web checkout
- App Store subscriptions
- Freemium bottle caps

Optional future donations or tip jars only if product needs change — not in tree today.
